# 제품 개요

## 프로젝트 설명

본 프로젝트는 MoAI-ADK (Model Orchestrator AI - Application Development Kit) 프레임워크 v1.0.0으로 초기화된 개발 프로젝트입니다. 현재 애플리케이션 소스 코드가 구현되지 않은 초기 상태로, 프레임워크의 핵심 구성 요소와 개발 환경이 준비되어 있습니다.

## 대상 사용자

- Claude Code 사용자
- AI 기반 개발 워크플로우를 활용하는 개발자
- 테스트 주도 개발(TDD)을 선호하는 엔지니어
- 자동화된 품질 관리 시스템을 도입하고자 하는 팀

## 핵심 프레임워크 기능

### SPEC 기반 개발 시스템

EARS(Easy Approach to Requirements Syntax) 형식을 사용하는 명세서 우선 개발 방식을 제공합니다. 모든 기능은 명확한 요구사항 명세서부터 시작하여 테스트 주도 개발(TDD)으로 구현됩니다.

### TDD 워크플로우

RED-GREEN-REFACTOR 사이클을 기반으로 한 테스트 주도 개발을 지원합니다. manager-tdd 에이전트가 자동으로 85% 이상의 테스트 커버리지를 보장합니다.

### TRUST 5 품질 프레임워크

5가지 핵심 품질 원칙을 자동으로 적용합니다.

- **Test-first**: 최소 85% 테스트 커버리지 유지
- **Readable**: 명확한 네이밍 규칙과 코드 스타일
- **Unified**: 일관된 포맷팅과 임포트 패턴
- **Secured**: OWASP 보안 표준 준수
- **Trackable**: 구조화된 커밋 메시지

### 20개 전문 에이전트

개발 작업을 전담하는 20개의 전문화된 에이전트가 자동으로 작업을 처리합니다.

- 8개의 매니저 에이전트 (workflow 조율)
- 8개의 전문가 에이전트 (도메인별 구현)
- 4개의 빌더 에이전트 (에이전트/명령어/스킬/플러그인 생성)

### 10개 핵심 슬래시 명령어

개발 워크플로우를 간소화하는 10개의 명령어를 제공합니다.

- `/moai:0-project`: 프로젝트 구성 관리
- `/moai:1-plan`: 명세서 생성
- `/moai:2-run`: TDD 구현
- `/moai:3-sync`: 문서 동기화
- `/moai:alfred`: 지능형 라우팅
- `/moai:fix`: 빠른 수정
- `/moai:loop`: 반복 작업 자동화
- `/moai:cancel-loop`: 루프 중지
- `/moai:9-feedback`: 개선 피드백
- `/clear`: 컨텍스트 초기화

### Context7 MCP 통합

Upstash Context7 MCP 서버를 통해 최신 공식 문서와 라이브러리 정보를 실시간으로 조회할 수 있습니다. 개발 중 언제든지 최신 베스트 프랙티스를 참조할 수 있습니다.

## 개발 환경 요구사항

### 필수 구성 요소

- Python 3.10+ (프레임워크 훅 및 스크립트 실행용)
- Node.js 20+ (MCP 서버 및 프론트엔드 개발용)
- Git (버전 관리)
- Claude Code CLI (에이전트 및 명령어 실행)

### 선택적 구성 요소

- Docker: 컨테이너화된 개발 환경
- 데이터베이스: PostgreSQL, MongoDB, Redis (프로젝트 요구사항에 따라)
- 클라우드 플랫폼: 배포 및 인프라 관리

## 다음 단계

### 1단계: 프로젝트 계획

첫 번째 기능을 명확히 정의하고 `/moai:1-plan` 명령어로 명세서를 생성하세요.

```
/moai:1-plan "사용자 인증 시스템"
```

### 2단계: TDD 구현

생성된 명세서를 기반으로 `/moai:2-run` 명령어로 테스트 주도 개발을 진행하세요.

```
/moai:2-run SPEC-001
```

### 3단계: 문서화

구현 완료 후 `/moai:3-sync` 명령어로 문서를 자동 생성하세요.

```
/moai:3-sync SPEC-001
```

### 4단계: 반복

위 과정을 반복하여 프로젝트를 점진적으로 확장해 나가세요.
