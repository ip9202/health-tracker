# 제품 개요

## 프로젝트 설명

VIBE Health는 개인 건강 데이터 관리를 위한 풀스택 웹 애플리케이션입니다. InBody 체성분 결과지를 스캔하여 OCR로 데이터를 자동 추출하고, 시각화 및 기록 관리 기능을 제공합니다.

## 대상 사용자

- 자신의 체성분 변화를 체계적으로 관리하고자 하는 개인
- 정기적으로 InBody 측정을 수행하는 운동 및 건강 관리 애호가
- 건강 데이터 시각화를 통해 추이를 분석하고자 하는 사용자
- 회원가입 및 인증이 필요한 개인정보 보호 서비스 이용자

## 핵심 기능

### InBody 체성분 데이터 관리

#### 이미지 업로드

- Drag & Drop 방식의 직관적 파일 업로드 (react-dropzone)
- JPG/PNG 형식 지원 (최대 10MB)
- Magic bytes 검증으로 파일 위조 방지
- 실시간 업로드 진행률 표시

#### OCR 데이터 추출

- Tesseract.js를 활용한 클라이언트 측 OCR 처리
- InBody 결과지 이미지에서 텍스트 자동 추출
- 서버 의존 없이 브라우저에서 직접 처리

#### 데이터 파싱

- OCR 텍스트에서 구조화된 체성분 데이터 자동 추출
- 주요 지항: 체중, BMI, 체지방율, 골격근량, 기초대사량 등
- Zod 스키마를 통한 런타임 데이터 검증

#### 데이터 시각화

- Recharts 기반 인터랙티브 차트
- 체중, BMI, 체지방율 등 핵심 지표 추이 그래프
- 기간별 필터링 및 비교 분석

#### 기록 관리

- 페이지네이션을 통한 효율적 데이터 탐색
- 날짜별 필터링 및 정렬
- CRUD 작업 (생성, 조회, 수정, 삭제)

### 사용자 인증

#### 회원가입

- 이메일 기반 회원가입
- 이메일 중복 검증
- 비밀번호 복잡성 검증 (길이, 조합)
- bcryptjs로 안전한 비밀번호 해싱

#### 로그인/로그아웃

- JWT 기반 세션 관리 (30일 유효)
- 자동 로그인 유지
- 보안된 로그아웃 처리

#### 인증 보호

- 인증 미들웨어로 보호된 라우트
- 비인증 사용자 접근 제어
- 세션 만료 자동 처리

### 데이터 검증 및 보안

#### 런타임 검증

- Zod 스키마를 통한 타입 안전성 보장
- API 요청/응답 데이터 자동 검증
- 명확한 에러 메시지 제공

#### 파일 보안

- 이미지 파일 형식/크기 검증
- Magic bytes 검증으로 악의적 파일 업로드 방지
- 안전한 파일 저장소 관리

#### 비밀번호 보안

- bcryptjs로 안전한 해싱 (salt rounds: 10)
- 평문 비밀번호 저장 절대 불가
- 안전한 인증 처리

## 사용자 시나리오

### 시나리오 1: 첫 InBody 기록 등록

1. 회원가입 후 로그인
2. InBody 대시보드 접속
3. InBody 결과지 이미지를 Drag & Drop으로 업로드
4. OCR이 텍스트를 자동 추출
5. 시스템이 데이터를 파싱하여 구조화된 정보 표시
6. 저장 버튼으로 기록 확정

### 시나리오 2: 건강 추이 분석

1. 로그인 후 InBody 대시보드 접속
2. 기간별 필터로 최근 3개월 데이터 선택
3. 체중, BMI, 체지방율 차트로 변화 확인
4. 특정 기록 선택하여 상세 정보 조회
5. 필요시 데이터 수정 또는 삭제

### 시나리오 3: 새 기록 추가 및 비교

1. 최신 InBody 결과지 업로드
2. 이전 기록들과 비교하여 변화 확인
3. 목표 달성 여부 시각적 확인
4. 건강 관리 계획 수정 및 보완

## 기대 효과

### 개인 사용자

- 체성분 데이터 체계적 관리
- 건강 추이 시각적 파악

- React Server Components로 최적의 성능
