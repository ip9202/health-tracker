# 제품 개요

## 프로젝트 설명

VIBE Health는 개인 건강 데이터 관리를 위한 풀스택 웹 애플리케이션입니다. InBody 체성분 결과지를 스캔하여 OCR로 데이터를 자동 추출하고, AI 기반 건강 분석 및 추천 시스템을 통해 체계적인 건강 관리를 지원합니다.

## 대상 사용자

- 자신의 체성분 변화를 체계적으로 관리하고자 하는 개인
- 정기적으로 InBody 측정을 수행하는 운동 및 건강 관리 애호가
- 건강 데이터 시각화를 통해 추이를 분석하고자 하는 사용자
- AI 기반 건강 분석과 맞춤형 추천을 원하는 사용자
- 회원가입 및 인증이 필요한 개인정보 보호 서비스 이용자

## 핵심 기능

### InBody 체성분 데이터 관리

#### 이미지 업로드

- Drag & Drop 방식의 직관적 파일 업로드 (react-dropzone)
- JPG/PNG 형식 지원 (최대 10MB)
- Magic bytes 검증으로 파일 위조 방지
- 실시간 업로드 진행률 표시

#### OCR 데이터 추출

- Tesseract.js를 활용한 클라이언트 측 OCR 처리
- InBody 결과지 이미지에서 텍스트 자동 추출
- 서버 의존 없이 브라우저에서 직접 처리

#### 데이터 파싱

- OCR 텍스트에서 구조화된 체성분 데이터 자동 추출
- 주요 지항: 체중, BMI, 체지방율, 골격근량, 기초대사량 등
- Zod 스키마를 통한 런타임 데이터 검증

#### 데이터 시각화

- Recharts 기반 인터랙티브 차트
- 체중, BMI, 체지방율 등 핵심 지표 추이 그래프
- 기간별 필터링 및 비교 분석

#### 기록 관리

- 페이지네이션을 통한 효율적 데이터 탐색
- 날짜별 필터링 및 정렬
- CRUD 작업 (생성, 조회, 수정, 삭제)

### AI 기반 건강 분석 시스템 (NEW)

#### AI 건강 분석

- Anthropic Claude SDK 기반 AI 분석 엔진
- InBody 데이터를 활용한 종합 건강 상태 평가
- 0-100점 건강 점수 산출
- 개인별 맞춤형 위험 요소 식별

#### 건강 상태 카드

- 전체 건강 상태 시각화 (양호, 관리 필요, 개선 필요)
- 건강 점수 원형 차트 표시
- 주요 지표 요약 제공

#### 위험 요소 분석

- 체지방율, BMI, 근육량 등 기반 위험 요소 자동 식별
- 위험도별 카테고리 분류
- 우선순위별 관리 가이드 제공

#### 맞춤형 추천

- AI 기반 운동/생활 습관 추천
- 개인 건강 데이터에 최적화된 제안
- 실현 가능한 목표 설정 가이드

#### 주의 사항 알림

- 건강 관련 주의 사항 자동 생성
- 의료 전문가 상담 권장 안내
- 금기 사항 및 주의점 표시

### 사용자 인증

#### 회원가입

- 이메일 기반 회원가입
- 이메일 중복 검증
- 비밀번호 복잡성 검증 (길이, 조합)
- bcryptjs로 안전한 비밀번호 해싱

#### 로그인/로그아웃

- JWT 기반 세션 관리 (30일 유효)
- 자동 로그인 유지
- 보안된 로그아웃 처리

#### 인증 보호

- 인증 미들웨어로 보호된 라우트
- 비인증 사용자 접근 제어
- 세션 만료 자동 처리

### 데이터 검증 및 보안

#### 런타임 검증

- Zod 스키마를 통한 타입 안전성 보장
- API 요청/응답 데이터 자동 검증
- 명확한 에러 메시지 제공

#### 파일 보안

- 이미지 파일 형식/크기 검증
- Magic bytes 검증으로 악의적 파일 업로드 방지
- 안전한 파일 저장소 관리

#### 비밀번호 보안

- bcryptjs로 안전한 해싱 (salt rounds: 10)
- 평문 비밀번호 저장 절대 불가
- 안전한 인증 처리

## 사용자 시나리오

### 시나리오 1: 첫 InBody 기록 등록

1. 회원가입 후 로그인
2. InBody 대시보드 접속
3. InBody 결과지 이미지를 Drag & Drop으로 업로드
4. OCR이 텍스트를 자동 추출
5. 시스템이 데이터를 파싱하여 구조화된 정보 표시
6. 저장 버튼으로 기록 확정

### 시나리오 2: AI 건강 분석 활용

1. 최신 InBody 기록 업로드 완료
2. "AI 분석 요청" 버튼 클릭
3. AI가 데이터를 분석하여 건강 상태 평가
4. 건강 점수, 위험 요소, 추천 사항 확인
5. 맞춤형 운동/생활 습관 가이드 획득
6. 주의 사항 확인하고 건강 관리 계획 수립

### 시나리오 3: 건강 추이 분석

1. 로그인 후 InBody 대시보드 접속
2. 기간별 필터로 최근 3개월 데이터 선택
3. 체중, BMI, 체지방율 차트로 변화 확인
4. 특정 기록 선택하여 AI 분석 결과 상세 조회
5. 이전 분석 결과와 비교하여 건강 개선 추이 확인

### 시나리오 4: 새 기록 추가 및 AI 추천 활용

1. 최신 InBody 결과지 업로드
2. AI 분석으로 현재 건강 상태 파악
3. 이전 기록들과 비교하여 변화 확인
4. AI 추천을 활용하여 맞춤형 운동 계획 수립
5. 위험 요소 기반 목표 재설정
6. 주의 사항 확인하고 안전하게 건강 관리
