## 1. 테스트 시나리오 (Test Scenarios)

### Scenario Group 1: 이미지 전처리

#### TC-OCR-001: 기본 전처리 성공

**Given**: 사용자가 InBody 결과지 이미지를 업로드한다
**When**: 시스템이 이미지 전처리를 수행한다
**Then**: 다음 전처리 단계가 순차적으로 적용된다
  - 그레이스케일 변환 완료
  - 대비 향상 적용
  - 노이즈 제거 완료
  - 이진화 처리 완료
**And**: 이미지 품질 점수가 0-100 범위로 계산된다
**And**: 전처리 시간이 2초 이내이다

#### TC-OCR-002: 회전된 이미지 보정

**Given**: 사용자가 15도 회전된 InBody 이미지를 업로드한다
**When**: 시스템이 회전 감지를 수행한다
**Then**: 회전 각도가 정확히 감지된다 (오차 범위 ±2도)
**And**: 이미지가 자동으로 보정된다
**And**: OCR 처리 후 텍스트 추출이 가능하다

#### TC-OCR-003: 낮은 품질 이미지 향상

**Given**: 사용자가 흐릿하고 대비가 낮은 이미지를 업로드한다
**And**: 이미지 품질 점수가 50점 미만이다
**When**: 시스템이 전처리를 수행한다
**Then**: 대비가 20% 이상 향상된다
**And**: 노이즈가 감소한다
**And**: 품질 점수가 60점 이상으로 개선된다

### Scenario Group 2: 정규식 패턴 추출

#### TC-OCR-004: 표준 형식 신체점수 추출

**Given**: OCR 텍스트에 "신체 점수 100 표준"이 포함되어 있다
**When**: 시스템이 Priority 1 패턴으로 추출을 시도한다
**Then**: 신체점수 100이 정확히 추출된다
**And**: 추출 신뢰도가 90% 이상이다
**And**: 추가 패턴 시도 없이 바로 반환된다

#### TC-OCR-005: 포인트 형식 신체점수 추출

**Given**: OCR 텍스트에 "95/100포인트"가 포함되어 있다
**When**: 시스템이 Priority 2 패턴으로 추출을 시도한다
**Then**: 신체점수 95가 정확히 추출된다
**And**: 추출 신뢰도가 85% 이상이다

#### TC-OCR-006: 다양한 InBody 형식 지원

**Given**: 사용자가 InBody 770, 970, 720, OntoFit 앱 결과지를 각각 업로드한다
**When**: 시스템이 각 이미지에서 신체점수 추출을 시도한다
**Then**: 최소 90%의 이미지에서 신체점수가 추출된다
**And**: 각 형식별 성공률이 85% 이상이다

#### TC-OCR-007: 패턴 실패 시 대체 패턴 시도

**Given**: OCR 텍스트에 표준 형식이 포함되어 있지 않다
**When**: 시스템이 첫 번째 패턴으로 추출에 실패한다
**Then**: 다음 우선순위 패턴을 시도한다
**And**: 최대 10개 패턴까지 시도한다
**And**: 성공한 패턴의 ID가 로그에 기록된다

### Scenario Group 3: 다단계 추출 전략

#### TC-OCR-008: 높은 OCR 신뢰도 시 1단계 추출

**Given**: OCR 신뢰도가 85%이다
**When**: 시스템이 신체점수 추출을 시작한다
**Then**: Priority 1-3 패턴만 시도한다
**And**: 추출 성공 시 즉시 반환한다
**And**: 평균 시도 횟수가 2회 이내이다

#### TC-OCR-009: 중간 OCR 신뢰도 시 2단계 추출

**Given**: OCR 신뢰도가 65%이다
**When**: 시스템이 신체점수 추출을 시작한다
**Then**: Priority 4-7 패턴부터 시도한다
**And**: 실패 시 Priority 1-3 패턴도 시도한다
**And**: 평균 시도 횟수가 4회 이내이다

#### TC-OCR-010: 낮은 OCR 신뢰도 시 3단계 추출

**Given**: OCR 신뢰도가 40%이다
**When**: 시스템이 신체점수 추출을 시작한다
**Then**: Priority 8-10 패턴부터 시도한다
**And**: 실패 시 모든 패턴을 시도한다
**And**: 평균 시도 횟수가 7회 이내이다

### Scenario Group 4: OCR 설정 최적화

#### TC-OCR-011: 적절한 PSM 모드 선택

**Given**: 이미지의 텍스트 밀도가 분석된다
**When**: 시스템이 PSM 모드를 선택한다
**Then**: 텍스트 밀집 시 PSM 6이 선택된다
**And**: 여러 영역 시 PSM 3이 선택된다
**And**: 희소 텍스트 시 PSM 11이 선택된다

#### TC-OCR-012: 신뢰도 임계값 상향 조정

**Given**: OCR 신뢰도가 45%이다
**When**: 시스템이 추출을 시도한다
**Then**: 50% 임계값이 적용된다
**And**: 낮은 신뢰도 경고가 사용자에게 표시된다
**And**: 전처리가 강화된다

### Scenario Group 5: 에러 처리

#### TC-OCR-013: 모든 패턴 실패 시 상세 에러

**Given**: 모든 패턴이 신체점수 추출에 실패한다
**When**: 시스템이 최종 결과를 반환한다
**Then**: 다음 정보가 포함된 에러가 반환된다:
  - 실패 원인 카테고리
  - 시도한 패턴 목록
  - OCR 신뢰도
  - 이미지 품질 점수
  - 권장 해결 방안

#### TC-OCR-014: 재시도 가능한 경우 재시도

**Given**: 첫 번째 추출이 실패한다
**And**: 이미지 품질 점수가 60점 이상이다
**When**: 시스템이 재시도를 수행한다
**Then**: 전처리가 강화된다 (대비 +20%)
**And**: OCR 처리가 재실행된다
**And**: 최대 2회까지 재시도된다

#### TC-OCR-015: 더미 데이터 반환 금지

**Given**: 모든 추출 시도가 실패한다
**When**: 시스템이 결과를 반환한다
**Then**: 더미 데이터가 반환되지 않는다
**And**: 사용자에게 수동 입력이 요청된다
**And**: 에러 메시지에 해결 가이드가 포함된다

#### TC-OCR-016: 범위를 벗어난 값 거부

**Given**: 패턴이 신체점수 150을 추출한다
**When**: 시스템이 검증을 수행한다
**Then**: 값이 거부된다 (0-100 범위 확인)
**And**: 다음 패턴이 시도된다
**And**: 로그에 "범위 초과"가 기록된다

### Scenario Group 6: 검증 및 품질 보증

#### TC-OCR-017: 추출 결과 신뢰도 계산

**Given**: Priority 2 패턴이 신체점수 85를 추출한다
**And**: OCR 신뢰도가 75%이다
**And**: 이미지 품질 점수가 80점이다
**When**: 시스템이 결과 신뢰도를 계산한다
**Then**: 종합 신뢰도 점수가 0-100 범위로 계산된다
**And**: 계산식: (패턴 가중치 × 0.4) + (OCR 신뢰도 × 0.3) + (품질 점수 × 0.3)
**And**: 결과: (85 × 0.4) + (75 × 0.3) + (80 × 0.3) = 80.5점

#### TC-OCR-018: 낮은 신뢰도 시 검토 요청

**Given**: 추출 결과의 신뢰도가 65점이다
**When**: 시스템이 사용자에게 결과를 표시한다
**Then**: "검토 요청" 알림이 표시된다
**And**: 추출된 값과 함께 신뢰도 점수가 표시된다
**And**: 사용자가 수정할 수 있는 UI가 제공된다

### Scenario Group 7: 성능 및 품질

#### TC-OCR-019: 전체 처리 시간

**Given**: 사용자가 5MB 크기의 InBody 이미지를 업로드한다
**When**: 시스템이 전체 파이프라인을 처리한다
**Then**: 전체 처리 시간이 20초 이내이다
**And**: 전처리 시간이 2초 이내이다
**And**: OCR 처리 시간이 15초 이내이다
**And**: 추출 시간이 1초 이내이다

#### TC-OCR-020: 메모리 사용량

**Given**: 브라우저에서 이미지 처리가 실행된다
**When**: 전처리 및 OCR이 수행된다
**Then**: 최대 메모리 사용량이 500MB 이내이다
**And**: 처리 후 메모리가 적절히 해제된다

#### TC-OCR-021: 벤치마크 테스트 성공률

**Given**: 100개의 실제 InBody 이미지가 준비된다
**And**: 각 형식별로 균등하게 분포된다
**When**: 시스템이 모든 이미지에서 신체점수 추출을 시도한다
**Then**: 전체 성공률이 95% 이상이다
**And**: 각 형식별 성공률이 90% 이상이다
**And**: 실패한 이미지에 대해 상세한 로그가 기록된다

### Scenario Group 8: API 인터페이스

#### TC-OCR-022: 추출 세부 정보 조회

**Given**: InBody 기록이 성공적으로 저장되었다
**When**: 사용자가 GET /api/inbody/extraction/[id]를 요청한다
**Then**: 다음 정보가 반환된다:

  - 사용된 패턴 ID
  - 시도 횟수
  - 각 시도의 상세 정보

#### TC-OCR-023: 재시도 API

**Given**: 이전 추출이 실패한 기록이 있다
**When**: 사용자가 POST /api/inbody/retry-extraction/[id]를 요청한다
**Then**: 강화된 전처리로 재시도가 수행된다
**And**: 새로운 추출 결과가 반환된다
**And**: 기록이 업데이트된다
