# SPEC-FE-006: 인수 기준

## 메타데이터

| 항목 | 값 |
|------|-----|
| **SPEC ID** | SPEC-FE-006 |
| **제목** | InBody UI/UX 전면 리디자인 인수 기준 |
| **버전** | 1.0.0 |
| **생성일** | 2026-01-25 |
| **도메인** | Frontend (UI/UX) |

## 개요

이 문서는 InBody 대시보드 전면 리디자인의 사용자 인수 기준을 정의합니다. Given-When-Then 형식의 시나리오 기반 테스트와 품질 게이트를 통해 새로운 디자인 시스템의 완성도를 검증합니다.

## 추적성 태그

- **TAG-FE-010**: 디자인 시스템 구축
- **TAG-FE-011**: 시각화 컴포넌트 재설계
- **TAG-FE-012**: 각성 요소 컴포넌트 재설계
- **TAG-FE-013**: 게이미피케이션 컴포넌트 재설계
- **TAG-FE-014**: 대시보드 레이아웃 재설계

## 1. 디자인 시스템 검증 (TAG-FE-010)

### AC-DS-001: 색상 시스템

**Given**: InBody 대시보드에 접속한 사용자
**When**: 페이지가 로드될 때
**Then**: InBody 공식 색상 팔레트가 일관되게 적용되어야 한다

**검증 기준**:
- [ ] Primary Blue (`#0066CC`)가 주요 브랜드 요소에 사용됨
- [ ] Success Green (`#22C55E`)이 정상 범위 표시에 사용됨
- [ ] Warning Orange (`#F97316`)이 주의 필요 표시에 사용됨
- [ ] 배경색이 의료용 흰색 (`#FFFFFF`)임
- [ ] 텍스트 색상이 충분한 대비비를 가짐

### AC-DS-002: 타이포그래피

**Given**: 대시보드의 모든 텍스트 콘텐츠
**When**: 사용자가 콘텐츠를 읽을 때
**Then**: 가독성 높은 폰트와 적절한 크기가 적용되어야 한다

**검증 기준**:
- [ ] 제목이 `Pretendard` 또는 `Inter` 폰트로 렌더링됨
- [ ] 본문이 14-16px 크기로 표시됨
- [ ] 숫자 데이터가 `Roboto Mono`로 강조됨
- [ ] 라인 높이가 1.5-1.8로 설정됨
- [ ] 모든 텍스트가 한국어 최적화되어 있음

### AC-DS-003: 간격 및 레이아웃

**Given**: 대시보드의 모든 레이아웃 요소
**When**: 사용자가 페이지를 탐색할 때
**Then**: 8px 기반 그리드 시스템이 일관되게 적용되어야 한다

**검증 기준**:
- [ ] 카드 간격이 16-24px로 설정됨
- [ ] 섹션 간격이 32-48px로 설정됨
- [ ] 컨테이너 최대 너비가 1200px로 제한됨
- [ ] 모든 간격이 8px의 배수로 설정됨

### AC-DS-004: 컴포넌트 스타일 일관성

**Given**: 대시보드의 모든 UI 컴포넌트
**When**: 사용자가 다양한 컴포넌트를 사용할 때
**Then**: 일관된 InBody 스타일이 적용되어야 한다

**검증 기준**:
- [ ] 둥근 모서리가 4-8px로 최소화됨
- [ ] 그림자가 미세하게만 적용됨
- [ ] 테두리가 1px solid `#E5E7EB`로 설정됨
- [ ] 호버 효과가 미세한 배경색 변화로 표시됨

## 2. 시각화 컴포넌트 검증 (TAG-FE-011)

### AC-VIZ-001: 바디 타입 쉐이프

**Given**: 사용자가 자신의 체성분 결과를 조회할 때
**When**: 바디 타입 분석 결과가 표시될 때
**Then**: C/I/D 타입이 명확하게 시각화되어야 한다

**시나리오**:

```gherkin
Scenario: C-Type 사용자의 바디 타입 시각화
  Given 사용자가 골격근량 부족 상태(C-Type)일 때
  When 바디 타입 쉐이프 컴포넌트가 렌더링되면
  Then 인체 실루엣이 Blue 색상으로 표시되어야 한다
  And "골격근량 부족" 메시지가 표시되어야 한다
  And 호버 시 상세 정보가 표시되어야 한다

Scenario: I-Type 사용자의 바디 타입 시각화
  Given 사용자가 이상적인 균형 상태(I-Type)일 때
  When 바디 타입 쉐이프 컴포넌트가 렌더링되면
  Then 인체 실루엣이 Green 색상으로 표시되어야 한다
  And "이상적인 균형" 메시지가 표시되어야 한다
  And 축하 메시지가 표시되어야 한다

Scenario: D-Type 사용자의 바디 타입 시각화
  Given 사용자가 근육/지방 불균형 상태(D-Type)일 때
  When 바디 타입 쉐이프 컴포넌트가 렌더링되면
  Then 인체 실루엣이 Orange 색상으로 표시되어야 한다
  And "근육/지방 불균형" 메시지가 표시되어야 한다
  And 개선 추천이 표시되어야 한다
```

**검증 기준**:
- [ ] SVG 실루엣이 명확하게 렌더링됨
- [ ] 색상이 타입별로 올바르게 적용됨
- [ ] 호버 시 상세 정보가 표시됨
- [ ] 반응형 크기 조정이 작동함

```gherkin
Scenario: 정상 범위 내 ECW/TBW 비율

  Then 비율이 Green 색상으로 표시되어야 한다
  And "정상 범위" 메시지가 표시되어야 한다
  And 퍼센트 값이 명시되어야 한다

Scenario: 높은 ECW/TBW 비율

  Then 비율이 Orange 색상으로 표시되어야 한다
  And "주의 필요" 메시지가 표시되어야 한다
  And 정상 범위 하이라이트가 표시되어야 한다

Scenario: 낮은 ECW/TBW 비율
  Given 사용자의 ECW/TBW 비율이 0.35일 때
  When ECW/TBW 차트가 렌더링되면
  Then 비율이 Orange 색상으로 표시되어야 한다
  And "주의 필요" 메시지가 표시되어야 한다
  And 수분 섭취 추천이 표시되어야 한다
```

**검증 기준**:
- [ ] 원형 게이지 차트가 올바르게 렌더링됨
- [ ] 정상 범위(0.38-0.39)가 하이라이트됨
- [ ] 색상 그라데이션이 적용됨
- [ ] 퍼센트 값이 정확하게 표시됨

### AC-VIZ-003: 트렌드 스파크라인

**Given**: 사용자가 건강 데이터 추이를 확인할 때
**When**: 스파크라인 차트가 표시될 때
**Then**: 최근 7-30일 데이터의 추세가 명확하게 표시되어야 한다

**시나리오**:

```gherkin
Scenario: 체중 증가 추세
  Given 사용자의 체중이 최근 7일간 증가 추세일 때

  Then 라인이 Blue 색상으로 표시되어야 한다
  And 상승 아이콘이 표시되어야 한다
  And 증가율 퍼센트가 명시되어야 한다

Scenario: 체중 감소 추세
  Given 사용자의 체중이 최근 7일간 감소 추세일 때
  When 트렌드 스파크라인이 렌더링되면
  Then 라인이 Green 색상으로 표시되어야 한다
  And 하락 아이콘이 표시되어야 한다

Scenario: 체중 유지 추세

  And 변화없음 메시지가 표시되어야 한다
```

**검증 기준**:
- [ ] 미니멀한 라인 차트가 렌더링됨
- [ ] 최근 7-30일 데이터가 표시됨
- [ ] 양/음 변화 색상 구분이 명확함
- [ ] 애니메이션이 최소화됨

```gherkin
Scenario: 상체 근육 부족
```

- [ ] 호버 시 툴팁이 표시됨

### AC-VIZ-005: 비교 분석 차트

**Given**: 사용자가 현재와 과거 데이터를 비교할 때
**When**: 비교 차트가 표시될 때
**Then**: Before/After 변화가 명확하게 하이라이트되어야 한다

**시나리오**:

```gherkin
Scenario: 체중 감소 비교
  Given 사용자가 이번 달과 지난 달 데이터를 비교할 때
  And 체중이 2kg 감소했을 때
  When 비교 차트가 렌더링되면
  Then Before 막대와 After 막대가 나란히 표시되어야 한다
  And 감소분이 Green 색상으로 하이라이트되어야 한다
  And "-2kg (-2.5%)" 메시지가 표시되어야 한다

Scenario: 체지방률 증가 비교
  Given 사용자가 이번 달과 지난 달 데이터를 비교할 때
  And 체지방률이 1.5% 증가했을 때
  When 비교 차트가 렌더링되면
  Then Before 막대와 After 막대가 나란히 표시되어야 한다
  And 증가분이 Orange 색상으로 하이라이트되어야 한다
  And "+1.5% (+3.2%)" 메시지가 표시되어야 한다
```

**검증 기준**:
- [ ] Before/After 막대 그래프가 렌더링됨
- [ ] 변화율 퍼센트가 정확히 계산됨
- [ ] 색상으로 양/음 변화가 구분됨
- [ ] 애니메이션 효과가 적용됨

## 3. 각성 요소 컴포넌트 검증 (TAG-FE-012)

### AC-AWR-001: 변화 하이라이트

**Then**: 양/음 변화가 명확하게 시각화되어야 한다

**시나리오**:

```gherkin
Scenario: 긍정적인 변화 하이라이트

  When 변화 하이라이트가 렌더링되면

  And "+1kg" 메시지가 Green 색상으로 표시되어야 한다
  And "좋아요! 계속 유지하세요" 메시지가 표시되어야 한다

Scenario: 부정적인 변화 하이라이트
  Given 사용자의 체지방륨이 2% 증가했을 때
  When 변화 하이라이트가 렌더링되면

  And "+2%" 메시지가 Orange 색상으로 표시되어야 한다
  And "주의 필요" 메시지가 표시되어야 한다
```

**검증 기준**:
- [ ] 전후 데이터가 명확히 비교됨
- [ ] 양/음 변화 색상 및 아이콘이 올바름
- [ ] 퍼센트 변화가 정확히 표시됨

```gherkin
Scenario: 목표 50% 달성
```

- [ ] 색상으로 진행 상태가 구분됨
